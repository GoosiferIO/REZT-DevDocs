# Welcome

The **OpenZT** team is dedicated to the effort of reverse engineering Zoo Tycoon.

There are two main projects that are part of this effort. **ZT EMU** (Extensible Modding Utility) aims to offer a modding platform that allows community creators the ability to manipulate the game in ways they haven't before. A big inspiration behind this project was Skyrim SKSE.

**OpenZT** is an ambitious mod that aims to rewrite the game using open standards and introduce quality of life improvements and bug fixes. A couple of inspirations are the [OpenRCT2](https://openrct2.io/) and [OpenTTD](https://www.openttd.org/) projects.

This effort is a multi-year commitment and we have a great core team working on it. Plans to announce OpenZT publicly are not in the pipeline yet as we focus our time on reverse-engineering the code and binary formats. Until then, **ZT EMU** acts a proof of concept that we can serve in the short term and apply what we've reversed before we fully transition to **OpenZT** development.
